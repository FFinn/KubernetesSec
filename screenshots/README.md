# Доказательства

В `evidence/` находятся реальные текстовые выводы команд и JSON отчёты с локального Mac от 17.10.2026. Скриншоты терминала не имитировались. `comparison.md` — сравнение До/После, рассчитанное из JSON. Файлы не содержат kubeconfig; значения Secret и last-applied annotations в публичных копиях JSON скрыты скриптом `redact-scan.py`.

Исходные JSON лежат в игнорируемой `.local/` с ограниченным доступом. Финальный Kubescape сделан до установки Falco: привилегии системного сенсора не смешаны с оценкой исправлений приложений. Диагностика Falco сохранена отдельно.
